# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-20

### Added

- **Character Forge**: randomised generation across 10 classes and 8 races, with
  D&D-style ability scores, signature abilities, equipment, lore and portraits.
- **Collectible Player Cards** with health, mana, core stats and rarity tiers.
- **Saved Deck** backed by `localStorage`, so characters persist between visits
  with no backend and no account.
- **Class Compendium**: a browsable reference for every class, its role, hit die
  and signature abilities.
- **Dice Sandbox**: interactive dice rolling with animated results.
- **Web Audio SFX** synthesised in the browser, with a mute toggle.
- MIT license, contribution guide, code of conduct, and issue / pull request
  templates.
- CI workflow that type-checks and builds the project on every pull request.
